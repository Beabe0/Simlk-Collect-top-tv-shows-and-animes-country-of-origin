# Simlk-Collect-top-tv-shows-and-animes-country-of-origin
I wanted to collect data to analyze, at a later stage, the rise of non-U.S. TV series. For this purpose, the Simkl Lists API was the most accessible option, even though it is not the most widely used tracking app among users.
This code retrieves the top 100 TV shows and top 100 anime for the day; since the API handles these as separate categories, the data sets were subsequently merged.
Following this, information regarding the country of origin was collected. Note that this information is not available for every item.
